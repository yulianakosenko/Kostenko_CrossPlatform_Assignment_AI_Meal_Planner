# AI Meal Planner App

Premium cross-platform React Native application for generating personalized AI meal plans.

## Features

- AI meal plan generation
- Nutrition goals
- Shopping list
- Meal history
- AsyncStorage persistence
- React Navigation
- Modern premium UI

## Technologies

- React Native
- Expo
- React Navigation
- AsyncStorage
- JavaScript

## Screens

- Home
- Processing
- Summary
- Meal Plan
- Shopping List
- History

## Installation

```bash
npm install
npx expo start
```
